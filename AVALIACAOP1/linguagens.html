Conteúdos Estudados

Linguagens de Programação explora conceitos fundamentais sobre desenvolvimento de sistemas usando diferentes paradigmas e linguagens. Os tópicos principais incluem:

  • Introdução a linguagens de programação e seus paradigmas;
  • Estruturas de dados e manipulação;
  • Programação orientada a objetos;
  • Boas práticas e técnicas avançadas de programação.

A disciplina prepara os alunos para desenvolver sistemas robustos e compreender diferentes ambientes de desenvolvimento.
